## 🔬 หลักการกำจัดเมฆและรักษาอุณหภูมิจริง (Methodology)

### 1. ทำไมโค้ดเดิมถึงมีดวงสีขาวหลงเหลือ?
* พาเลท `min: 20` กำหนดให้ค่า $\le 20^\circ\text{C}$ กลายเป็นสีขาวจ้า (`#FFFFFF`) เมื่อยอดเมฆหรือไอความเย็นรอบขอบเมฆ ($5^\circ\text{C} - 18^\circ\text{C}$) หลุดรอดมา จึงกลายเป็นจุดขาวเด่นชัด
* โค้ดเดิมขาดการตรวจจับ **Bit 1 (Dilated Cloud)** และระยะ Buffer เพียง 1.5 พิกเซล (45 เมตร) ไม่เพียงพอกับแบนด์ความร้อนของ Landsat 5 ที่มีความละเอียดเซนเซอร์ดั้งเดิม 120 เมตร

### 2. วิธีการแก้ไขในเวอร์ชันนี้:
1. **QA Bitwise Masking:** ตรวจจับ Fill (Bit 0), Dilated Cloud (Bit 1), Cloud (Bit 3), และ Cloud Shadow (Bit 4)
2. **Confidence Filtering:** กรอง Cloud Confidence ระดับปานกลางและสูงออก (`< 2`) และตัดเฉพาะ High Shadow (`!= 3`) เพื่อป้องกันไม่ให้กินผืนน้ำอ่าวไทยและนาเกลือ
3. **Thermal Buffer 150 เมตร:** ขยายขอบเขตตัดรอบก้อนเมฆออกไป 150 เมตร เพื่อลบขอบขาวและไอความเย็นรอบก้อนเมฆทิ้งทั้งหมด
4. **Physical Temperature Threshold:** กำหนดเกณฑ์ $\ge 20.0^\circ\text{C}$ เพื่อตัดยอดเมฆตกค้างทิ้งเด็ดขาด
5. **Seasonal Median & Annual Fallback:**
   * คำสั่ง `.median()` จะคำนวณเฉพาะวันที่ท้องฟ้าโปร่งของพิกเซลนั้น
   * ใช้ `.unmask(lstAnnual_clean)` เพื่อดึงค่าอุณหภูมิจริงจากภาพเฉลี่ยทั้งปี 1989 มาอุดช่องว่างเฉพาะจุดที่โดนเมฆบังทุกภาพในฤดูกาลนั้น ทำให้ภาพเต็มผืนจังหวัด 100% โดยไม่มีก้อนเมฆและไม่มีรูโหว่
